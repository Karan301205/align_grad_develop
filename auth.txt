## Google & GitHub OAuth — Requirements Checklist

### 🔑 1. OAuth Provider Credentials (You need to create these)

#### Google
- **Google Cloud Console** project → [console.cloud.google.com](https://console.cloud.google.com)
- Enable **Google Identity / OAuth 2.0** API
- Create **OAuth 2.0 Client ID** (type: Web Application)
- Set **Authorized redirect URI**: `http://localhost:5001/api/auth/google/callback` (dev) + your production domain
- You'll get: `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET`

#### GitHub
- **GitHub Developer Settings** → [github.com/settings/developers](https://github.com/settings/developers)
- Create a new **OAuth App**
- Set **Authorization callback URL**: `http://localhost:5001/api/auth/github/callback` (dev) + your production domain
- You'll get: `GITHUB_CLIENT_ID` and `GITHUB_CLIENT_SECRET`

### 🔄 7. OAuth Flow (How it works end-to-end)

```
1. User clicks "Sign in with Google" on frontend
2. Frontend redirects to → GET /api/auth/google
3. Backend (Passport) redirects to → Google's consent screen
4. User approves → Google redirects to → GET /api/auth/google/callback
5. Backend receives Google profile → finds or creates User in MongoDB
6. Backend issues JWT → redirects to frontend with ?token=xxx&user=yyy
7. Frontend App.jsx reads URL params → stores token + user in localStorage
```
